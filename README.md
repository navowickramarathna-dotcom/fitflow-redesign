# FitFlow Redesign - Mobile Application Architecture & Implementation

## Overview
FitFlow is an AI-powered fitness tracking platform designed to improve retention, reduce nutrition tracking friction, and eliminate social isolation through personalized adaptive workouts and safe social circles.

## Repository Folder Structure
- `/frontend`: React Native mobile application codebase setup.
- `/backend`: Node.js NestJS core API services layout.
- `/ai-service`: Python FastAPI adaptive recommendation and computer vision engine setup.
- `/docs`: System architecture diagrams, ADRs, and HCI lab reports.

## Tech Stack
- **Frontend:** React Native (Expo, TypeScript)
- **Core Backend:** Node.js (NestJS, WebSockets)
- **AI Microservice:** Python (FastAPI, PyTorch, OpenCV)
- **Database:** PostgreSQL & Redis
- **Auth:** Firebase Authentication
- **Storage:** Cloud Object Storage (S3)
